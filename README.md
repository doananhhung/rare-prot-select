# rare-prot-select

## Đề tài 2: Chọn tập protein đại diện có ưu tiên nhóm hiếm bằng tối ưu hóa submodular (RareProtSelect)

A submodular optimization framework for representative protein sequence selection prioritizing rare subfamilies using ESM-2 representations.

### Repository Overview
- `RareProtSelect/`: Mã nguồn cốt lõi Python, cấu hình thực nghiệm và pipeline submodular.
- `baseline_repo/`: Các tập dữ liệu đối chuẩn sinh học (`Thioesterases`, `MEROPS_A1A`, `CE`) và script cơ sở.
- Tài liệu nghiên cứu chi tiết:
  - [**`quy_trinh_thuc_hien_va_cac_cong_doan.md`**](./quy_trinh_thuc_hien_va_cac_cong_doan.md): [Tài liệu 1] Quy trình nghiên cứu khoa học (SSOT).
  - [**`thiet_ke_codebase_va_kien_truc_he_thong.md`**](./thiet_ke_codebase_va_kien_truc_he_thong.md): [Tài liệu 2] Bản thiết kế codebase & kiến trúc hệ thống (SSOT).
  - [**`tong_hop_cac_chi_so_danh_gia.md`**](./tong_hop_cac_chi_so_danh_gia.md): Tổng hợp toàn diện 15+ chỉ số đánh giá 3 tầng (Nội tại, Hạ nguồn, Hiệu năng).
  - [**`giai_thich_thuat_toan_va_thuoc_do.md`**](./giai_thich_thuat_toan_va_thuoc_do.md): Chuyên đề giải phẫu thuật toán, bóc tách E-value và dẫn chứng bình duyệt quốc tế.
  - [**`bao_cao_ket_qua_chi_tiet_topic2.md`**](./bao_cao_ket_qua_chi_tiet_topic2.md): Báo cáo kết quả thực nghiệm chi tiết 5 nhánh kèm 16 biểu đồ và 8 bảng số liệu.
